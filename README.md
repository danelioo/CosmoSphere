# CosmoSphere (JUCE 7.0.12)
Sintetizador hibrido (eletronico + organico), 8 vozes, 17 presets, VST3 + Standalone.

1. Substitua TODO o conteudo do repositorio por esta pasta (CMakeLists.txt, Source/, .github/).
2. Faca commit/push. Em Actions, abra o build e baixe o artifact "CosmoSphere-VST3-Windows".
3. Copie a PASTA CosmoSphere.vst3 inteira para C:\Program Files\Common Files\VST3
4. No FL Studio: Options > Manage plugins > Find plugins.
O artifact "Standalone" abre o synth sem DAW (teclado do PC nao toca; use MIDI).

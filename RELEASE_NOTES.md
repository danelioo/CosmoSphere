# Cosphere 1.0.0 — UI and preset refinement

- 89 factory presets categorized by genre, including Pop, Rock, Dance, Funk and Latin.
- Renamed Organic to Acoustic & Orchestral.
- Purpose-built effects panel with a dedicated Delay section and adjacent Reverb/Size knobs.
- Modulation and Delay have independent BPM sync enabled by default, including triplet notes.
- Exact global editor width stored and restored, with aspect ratio preserved.
- Redesigned Options dialog and clickable GitHub project link in About.
- Portable VST3 and standalone Windows artifacts only (no installer).

Build artifacts must be compiled and tested on Windows before release.
